# Лабораторная работа № 5

## Гостевое веб-приложение на React для сервиса расчёта ежемесячных процентных выплат по банковскому вкладу

Услуга в проекте — расчётный месяц. Экономист может найти месяц по количеству календарных дней, открыть его карточку в ленте и посмотреть описание и видео. Приложение разработано на React и TypeScript с использованием Vite и React-Bootstrap.

Приложение включает четыре страницы. В ЛР5 гостю доступны **«Плитка»** и **«Лента»**. Обе страницы получают данные из локальной mock-коллекции `mockDepositMonths`, в которой восемь опубликованных расчётных месяцев с января по август. Для страниц **«Добавление»** и **«Вход»** ниже описаны поля и действия, предусмотренные ТЗ. В нижней панели ЛР5 эти два пункта неактивны.

## Страницы приложения

### 1. Плитка «Расчётные месяцы» — `/deposit_month/list`

Страница открывается через пункт **«Плитка»** в нижней панели. Гость выбирает диапазон дней и нажимает на карточку, чтобы посмотреть выбранный месяц в ленте.

#### Шапка

Над фильтром расположен заголовок **«Расчётные месяцы»**.

#### Фильтр «Количество дней» (`DaysFilter`)

| Элемент | Тип | Что делает |
| --- | --- | --- |
| Нижняя граница | Левый ползунок | Задаёт минимальное количество дней. Начальное значение — 28. |
| Верхняя граница | Правый ползунок | Задаёт максимальное количество дней. Начальное значение — 31. |
| «Найти» | Кнопка | Применяет выбранный диапазон. В результат входят месяцы, количество дней в которых совпадает с границей диапазона. |

Шаг ползунков — один день. Если выбрать **28–30** и нажать **«Найти»**, в плитке останутся февраль, апрель и июнь. Если совпадений нет, появится сообщение «Месяцы в выбранном диапазоне не найдены».

#### Список карточек (`DepositMonthCard`)

Карточки расположены в две колонки.

| Элемент | Тип | Что делает |
| --- | --- | --- |
| Обложка | Изображение | Показывает фотографию месяца. Если `image_url` пустое или файл не загрузился, выводится `default.jpg`. |
| Номер и название месяца | Текст | Показывают порядковый номер месяца в году и его название. |
| Количество дней | Текст | Показывает продолжительность месяца, например «31 день» или «28 дней». |
| ♡ и число рядом | Счётчик | Показывает количество лайков. Гостю доступен просмотр. |

#### Переход из карточки

Вся карточка работает как ссылка. Нажатие на **«Февраль»** открывает ленту по адресу `/deposit_month?deposit_month_id=2`. В ссылку передаётся `id` месяца из mock-коллекции, поэтому после фильтрации открывается тот же февраль, даже если он оказался первым в плитке.

### 2. Лента — `/deposit_month`

При входе через нижний пункт **«Лента»** открывается январь. При переходе из плитки лента сразу показывает месяц, на который нажал гость.

#### Видео месяца

Видео заполняет область ленты над нижней панелью, автоматически воспроизводится без звука и повторяется. Если `video_url` пустое или файл не загрузился, используется локальное видео `default.mp4`.

#### Название и описание

| Элемент | Тип | Что делает |
| --- | --- | --- |
| Название месяца | Заголовок | Показывает, какой месяц открыт в ленте. |
| Описание | Текст | Отображается поверх видео. В свёрнутом виде занимает до двух строк. |
| «Ещё» / «Свернуть» | Кнопка | Появляется, когда описание длиннее двух строк. Раскрывает полный текст и позволяет свернуть его обратно. |

#### Боковая панель

| Элемент | Тип | Что делает |
| --- | --- | --- |
| Номер месяца | Числовой показатель | Показывает порядковый номер месяца в году. |
| Количество дней | Числовой показатель | Показывает продолжительность открытого месяца. |
| ♡ и число под ним | Счётчик | Показывает количество лайков. |
| → «Следующий месяц» | Кнопка | Открывает следующий месяц и обновляет видео, описание и показатели. |

#### Переключение месяцев

Если открыть февраль из отфильтрованной плитки и нажать **→**, появится март. Листание идёт по всей коллекции. После августа снова открывается январь.

### 3. Добавление расчётного месяца

По ТЗ страница предназначена для авторизованного создателя. При открытии загружается его текущий черновик. Если черновик уже есть, создатель может продолжить с этапа публикации. В ЛР5 пункт **«Добавление»** неактивен.

#### Создание черновика

| Элемент | Тип | Что делает |
| --- | --- | --- |
| Название | Текстовое поле | Задаёт название нового расчётного месяца. |
| Изображение | Поле выбора файла | Позволяет выбрать обложку для карточки в плитке. |
| Видео | Поле выбора файла | Позволяет выбрать ролик для воспроизведения в ленте. |
| «Далее» | Кнопка | Создаёт черновик с выбранными материалами и открывает форму публикации. |

#### Публикация

| Элемент | Тип | Что делает |
| --- | --- | --- |
| Название | Текстовое поле | Позволяет проверить и изменить название из черновика. |
| Описание | Многострочное текстовое поле | Задаёт текст, который будет виден в ленте. |
| Номер месяца | Числовое поле | Задаёт порядковый номер месяца в году. |
| Количество календарных дней | Числовое поле | Задаёт продолжительность месяца. Это значение используется в фильтре плитки. |
| «Опубликовать» | Кнопка | Публикует расчётный месяц и возвращает создателя на страницу «Расчётные месяцы». |

### 4. Вход

По ТЗ на этой странице гость входит в существующую учётную запись или регистрируется в системе. В ЛР5 пункт **«Вход»** неактивен.

#### Форма входа

| Элемент | Тип | Что делает |
| --- | --- | --- |
| Электронная почта | Поле ввода адреса | Принимает адрес, указанный при регистрации. |
| Пароль | Поле ввода пароля | Принимает пароль пользователя и скрывает введённые символы. |

#### Действия

| Элемент | Тип | Что делает |
| --- | --- | --- |
| «Войти» | Кнопка | Отправляет электронную почту и пароль на проверку. После успешного входа пользователю доступны действия создателя. |
| «Зарегистрироваться» | Кнопка | Служит для создания учётной записи. Для регистрации требуются ФИО, дата рождения, электронная почта и пароль. |

## Нижняя навигационная панель

| Пункт | Доступен гостю в ЛР5 | Действие в ЛР5 |
| --- | --- | --- |
| Лента | Да | Открывает ленту с января. |
| Добавление | Нет | Пункт отображается неактивным. |
| Плитка | Да | Открывает список расчётных месяцев с фильтром по количеству дней. |
| Вход | Нет | Пункт отображается неактивным. |

Активный пункт подсвечивается. При нажатии на карточку месяца подсветка переключается с **«Плитки»** на **«Ленту»**.
