# Лабораторная работа № 5

## Гостевое веб-приложение на React для сервиса расчёта ежемесячных процентных выплат по банковскому вкладу

Услуга в проекте — расчётный месяц. Гость может выбрать месяц по количеству календарных дней и посмотреть его описание и видео. Приложение разработано на React и TypeScript с использованием Vite и React-Bootstrap.

В гостевом интерфейсе доступны два экрана — **плитка** и **лента**. Оба получают данные из локальной mock-коллекции `mockDepositMonths`, в которой восемь опубликованных месяцев с января по август. Запросы к Go API для просмотра карточек не требуются.

## Страницы приложения

### 1. Плитка «Расчётные месяцы» — `/deposit_month/list`

Открывается через пункт «Плитка» нижней панели и воспроизводит страницу списка расчётных месяцев из ЛР1.

#### Шапка

Заголовок «Расчётные месяцы» расположен над фильтром.

#### Фильтр «Количество дней» (`DaysFilter`)

| Элемент | Тип | Что делает |
| --- | --- | --- |
| Нижняя граница | Левый ползунок | Задаёт минимальное количество дней. Начальное значение — 28. |
| Верхняя граница | Правый ползунок | Задаёт максимальное количество дней. Начальное значение — 31. |
| «Найти» | Кнопка | Показывает месяцы, которые попадают в выбранный диапазон, включая обе границы. |

Шаг ползунков — один день. Если выбрать **28–30** и нажать **«Найти»**, в плитке останутся февраль, апрель и июнь. Если совпадений нет, вместо карточек появится сообщение «Месяцы в выбранном диапазоне не найдены».

#### Список карточек (`DepositMonthCard`)

Карточки расположены в две колонки.

| Элемент | Тип | Что делает |
| --- | --- | --- |
| Изображение месяца | Изображение | Показывает обложку. Если поле `image_url` пустое или файл не загрузился, выводится `default.jpg`. |
| Номер и название | Текст | Показывают порядковый номер месяца в году и его название. |
| Количество дней | Текст | Показывает продолжительность месяца, например «31 день» или «28 дней». |
| ♡ и число рядом с ним | Счётчик | Показывает количество лайков. Гостю доступен только просмотр. |

#### Переход из карточки

Вся карточка работает как ссылка. Нажатие на «Февраль» открывает ленту по адресу `/deposit_month?deposit_month_id=2`. В ссылку передаётся идентификатор месяца из mock-коллекции, поэтому переход работает и после фильтрации.

### 2. Лента — `/deposit_month`

Пункт «Лента» в нижней панели открывает январь. При переходе из плитки лента сразу показывает месяц, выбранный в карточке.

#### Видео месяца

Видео заполняет область ленты над нижней панелью, автоматически запускается без звука и повторяется. Если поле `video_url` пустое или файл не загрузился, воспроизводится локальное видео `default.mp4`.

#### Название и описание

| Элемент | Тип | Что делает |
| --- | --- | --- |
| Название месяца | Заголовок | Показывает, какой месяц открыт в ленте. |
| Описание | Текст | Отображает описание месяца поверх видео. В свёрнутом виде занимает до двух строк. |
| «Ещё» / «Свернуть» | Кнопка | Появляется, если описание длиннее двух строк. Раскрывает полный текст и позволяет свернуть его обратно. |

#### Боковая панель

| Элемент | Тип | Что делает |
| --- | --- | --- |
| Номер месяца | Числовое поле для чтения | Показывает порядковый номер месяца в году. |
| Количество дней | Числовое поле для чтения | Показывает продолжительность текущего месяца. |
| ♡ и число под ним | Счётчик | Показывает количество лайков. |
| → «Следующий месяц» | Кнопка | Переключает видео, описание и показатели на следующий месяц в ленте. |

#### Переключение месяцев

Если из плитки открыть февраль и нажать **→**, лента покажет март. Листание идёт по всей коллекции. После августа снова открывается январь.

## Нижняя навигационная панель

| Пункт | Доступен гостю | Действие |
| --- | --- | --- |
| Лента | Да | Открывает ленту с января. |
| Добавление | Нет | Неактивен. |
| Плитка | Да | Открывает список месяцев с фильтром по количеству дней. |
| Вход | Нет | Неактивен. |

Активный пункт подсвечивается. При переходе из карточки на видео выбранного месяца подсветка переключается с «Плитки» на «Ленту».
